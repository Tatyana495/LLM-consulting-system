# LLM Consulting System

Двухсервисная система LLM-консультаций.

## Сервисы

### auth-service

Сервис авторизации.

Отвечает за:

- регистрацию пользователей;
- проверку логина и пароля;
- выпуск JWT-токенов.

### bot-service

Telegram-бот для LLM-консультаций.

Отвечает за:

- работу с пользователем в Telegram;
- проверку JWT-токена;
- отправку запросов в OpenRouter.
